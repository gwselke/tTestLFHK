jamovi module tTestLFHK
=======================

This is a module for the jamovi statistical software.

The module provides just an ordinary t (and Wilcoxon and Mann-Whitney) test but
also displays the critical value(s) and other information and commentary
providing hints on how to interpret the results.

The module does not in any way purport to provide analyses hard to get by
otherwise. It is mainly used as a teaching tool at the Department of Biophysics
of the Medical Faculty of Charles University in Hradec Králové, Czech Republic
(Lékařská fakulta v Hradci Králové Univerzity Karlovy).


Installation hints
------------------

You can either start from the sources and build the module as described at
<https://dev.jamovi.org>

Or you can use the pre-compiled .jmo file provided here for "side-loading".
It has been prepared using jamovi 2.7.38 (solid) and should run on Windows
systems only.

For installation:

1. Start jamovi.
2. If you have a previous version of this module installed, be sure to remove
   it first:
	 1. Click on "+ Modules" near the top right corner of the jamovi window.
	 2. Choose "Manage installed".
	 3. Scroll to this module and click the "Remove" button.
2. Click on "+ Modules" near the top right corner of the jamovi window.
3. Choose "jamovi library".
4. Go to the "Sideload" tab.
5. Click on the empty space, navigate to the .jmo file, and select it.
